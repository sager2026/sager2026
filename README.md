## Featured Project

### [QuantMind — AI Quant Research Platform](https://github.com/sager2026/ai-quant-research-platform)

> **Where Quantitative Finance Meets AI Engineering.**

QuantMind is an open-source Financial AI research platform that combines:

```text
Financial Econometrics
        +
Quantitative Analysis
        +
PyTorch Forecasting
        +
SEC Filing RAG
        +
LangGraph Multi-Agent AI
        +
FastAPI / MCP
        +
AWS Cloud Infrastructure
```

Current v0.11 capabilities include:

- LangGraph-based conditional multi-agent research workflow
- LLM-driven research planning with a structured `ResearchPlan`
- deterministic technical-analysis pipeline
- PyTorch LSTM and Transformer forecasting
- SEC 10-K / 10-Q evidence retrieval
- Amazon Bedrock with Nova Lite
- Titan Text Embeddings V2
- Amazon S3 Vectors
- evidence-grounded specialist and synthesis agents
- FastAPI and Model Context Protocol (MCP) interfaces
- Docker + Amazon ECS / Fargate deployment
- Application Load Balancer, VPC, IAM, and CloudWatch
- demo-on-demand AWS operation

The system is designed for **AI-assisted investment research and decision support**, not autonomous trading.

## Research & Engineering Approach

I am especially interested in systems that separate:

```text
Data / Documents
        ↓
Deterministic Quantitative or Retrieval Layer
        ↓
Structured Evidence
        ↓
Specialized AI Reasoning
        ↓
Research Synthesis
        ↓
Human Decision
```

The goal is to use LLMs where probabilistic reasoning adds value while keeping quantitative computation, retrieval, workflow control, interfaces, and infrastructure explicit and testable.
